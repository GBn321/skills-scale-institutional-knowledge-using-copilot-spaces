# OctoAcme Project Management Docs

This repository contains the core project management process documents used by OctoAcme.

## Project management processes summary

OctoAcme uses a lightweight, cross-functional project management approach that spans the full project lifecycle: initiation, planning, execution, release, and retrospective. The team emphasizes customer value, iterative delivery, clear ownership, measurable outcomes, and proactive risk and stakeholder communication.

## Purpose of the docs

These documents provide a shared operating model for how OctoAcme defines scope, aligns stakeholders, tracks work, manages risks, and delivers outcomes with quality and visibility.
